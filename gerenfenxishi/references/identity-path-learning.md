# 主体、方向与学习 playbook

## 覆盖路由

- `agency-authorship`：融合 `calibrate-agency-and-responsibility` 与 `self-authorship-loop`。
- `path-fit`：承接 `qing-an-path-fit`。
- `learning-loop`：承接 `ming-shu-learning-loop`。

## 主体性与责任校准

1. **去身份化描述事件**：删除“失败者、没用、别人眼中的我”等标签，只写事件、时间和可观察影响。
2. **做三栏因果图**：
   - 可控：自己的具体选择和可改行为。
   - 可影响：可通过协商、求助、联合行动或换环境改变。
   - 不可控：他人自主行为、制度、概率、既成事实等。
3. **核验外部评价**：把反馈拆成行为事实、解释、价值判断和地位压力；只保留可验证且与目标有关的部分。
4. **承担有限责任**：对可控项写一次修正、补救或停止重复的动作；不得扩张为人格羞辱，也不得替施害、歧视、诈骗或结构性伤害承担责任。
5. **处理外因**：对可影响项选协商、求助或换环境；对不可控项选接受、缓冲、退出或重规划。
6. **重写角色**：列出头衔、家庭剧本和旧角色，再用跨时间的选择、作品、能力、回避模式和反馈替代标签。
7. **试演新角色**：选择一个愿承担后果的新角色，用可逆小行动验证；主体性只意味着拿回自己的行动权，不意味着控制他人。

## 道路适配

1. **列 2–4 个候选方向**：写成可试做的具体活动，不写抽象身份。
2. **收集三类证据**：
   - 投入感：是否愿意持续，做后能量如何。
   - 重复表现：是否能跨时间形成能力和稳定产物。
   - 外部价值：真实用户、同事、客户或受众是否得到价值。
3. **查现实代价**：收入、安全、照护、学习成本、机会成本与生活方式是否可承受。
4. **做 2–4 周试点**：设产物、频率、反馈对象、最大投入和停止线。
5. **比较而非神化轻松感**：按持续性、能力增长、价值、代价和选择权决定加码、保留或停止。

轻松投入感只能提出“可能适配”的假设；一次成功、夸奖、高薪或头衔都不能单独确认方向。

## 知行闭环

1. **一次只选一个方法**：把它绑定到一个当前真实问题。
2. **定义触发信号**：明确什么时候应该想起这个方法。
3. **设计最小动作**：要求在确定时间内完成，并产生可观察结果。
4. **实践并记录**：记录发生了什么、哪里没调用上、原理解哪里不够。
5. **重释而非背诵**：根据行为证据修改自己的理解；不能使用时回到场景，不继续囤积方法。
6. **迁移验证**：在第二个不同情境可复用，或能准确教给别人时，才标记本轮已掌握。

## 输出重点

- `agency-authorship` 必须给出可控、可影响、不可控三栏和一项责任动作。
- `path-fit` 必须给出候选方向、现有证据和一个低风险试点，不能直接宣布“天职”。
- `learning-loop` 必须把方法绑定到触发信号、最小行为和复盘点。
