# 复盘与整合 playbook

## 覆盖路由

- `outcome-review`：承接 `three-ledger-outcome-review`。

## 三账复盘

1. **定义原决定**：记录当时目标、假设、可得信息、预算、时间窗和停止线；不要只用事后结果评价当时判断。
2. **记即时账**：现金、时间、质量、安全、关系成本和原目标完成度，使用可核对结果。
3. **记经验账**：只登记能写成规则、流程、数据、模板或技能的学习；每条说明下次怎样使用。
4. **记长期势能账**：记录信誉、关系、能力、数据、选择权和未来机会的增减；每项必须有证据。
5. **记不可抵销项**：违法、严重伤害、伦理越界、击穿生活根基和重复无改善的损失，不能被“成长”或未来收益抵销。
6. **比较预测与实际**：指出判断对在哪里、错在哪里、哪些是运气、哪些是过程质量。
7. **合并判定**：选择继续、修正、缩小、暂停或退出，并给下一轮指标和复查点。

## 复盘后的路由

- 若用户被失败击垮、尚不能行动：转 `baseline-recovery`。
- 若争论“是否全是我的错”：转 `agency-authorship`。
- 若准备继续投入：转 `rooted-transition` 或 `money-downside`。
- 若成功掩盖新风险：转 `success-risk`。
- 若教训没有转成可调用行为：转 `learning-loop`。

## 输出重点

- 三张账必须分别呈现，不能用一张好账遮住另一张坏账。
- 明确哪些经验已经资产化，哪些只是感悟。
- 给出一个继续/修正/退出结论和下一轮可验证变化。
