# 关系、沟通与修复 playbook

## 覆盖路由

- `relationship-boundaries`：融合 `configure-trust-by-relationship`、`relationship-mode-layering` 与 `expectation-agency-separation`。
- `dialogue-repair`：融合 `truthful-equal-dialogue` 与 `partner-four-layer-repair`。

## 先筛安全

先检查家暴、胁迫、跟踪、经济控制、持续重大欺骗和人身安全。命中时停止普通关系修复，优先保护安全、保存必要证据并寻求专业支持。不得用宽容、感恩、家庭完整或“降低期待”要求受害者继续承受。

## 关系模式与边界

1. **命名当前角色**：援助、赠与、交易、友情、亲密、管理或混合；允许双方理解不同。
2. **分开三层**：
   - 情义投入：关心、陪伴、支持。
   - 利益交换：金钱、劳动、资源、权限。
   - 共同责任：已经明确同意的承诺和受影响者义务。
3. **查层间污染**：是否用情分压价、用合同逃避情感责任、用亲密要求违规，或用无偿帮助换控制权。
4. **写出隐性“应该”**：完整写成“因为我做了 X，所以对方应该 Y”。
5. **把 Y 分三类**：
   - 明确承诺：按协议核验和追责。
   - 可沟通请求：清楚表达，并允许对方拒绝。
   - 未经同意的期待：收回控制，重做自己的下一步。
6. **配置信任与核验**：亲密关系从尊重和平等开始；金钱、权限、共同资产和持续劳动仍需记录、里程碑和复核。
7. **定义边界与退出**：把宽容、和解、复信和继续接触视为四个不同决定；写明越界后的停止、补救、观察期、降级接触或退出。

## 一次真实平等的对话

1. **分事实、感受与推断**：未经核实的解释不得伪装成事实。
2. **组织表达**：按“事实—影响—需要—具体请求”表达，删除羞辱、传言、威胁和读心。
3. **降低威压**：明确允许不同意、不知道、补充事实和拒绝；平等不取消责任。
4. **核对理解**：复述双方观点，确认共同事实、分歧、未决问题和下一步。
5. **记录承诺**：涉及钱、时间、照护、权限或持续劳动时，写责任、期限、变更方式和复查点。

## 长期伴侣四层修复

1. **信任层**：是否存在可验证诚实、边界和稳定履约；没有地基时不直接要求和好。
2. **冲突修复层**：指出具体行为、影响、责任、补救和可验证承诺；时间本身不等于修复。
3. **能力互补层**：按能力、负荷和同意重谈分工，不把伴侣工具化。
4. **共同体层**：重大决定前内部对齐事实、底线和对外回应，同时保留个人安全与退出权。

只有双方能安全自由表达、愿意承担基本责任并允许验证时，才建议继续结构性修复。

## 输出重点

- 明确冲突属于关系角色、隐性期待、真实违约、沟通质量还是结构性修复中的哪一层。
- 给出一段可直接使用的事实化表达，以及边界、复查点和退出条件。
- 不把“谈钱伤感情”当原则；混合关系更需要分别把钱和情说清。
