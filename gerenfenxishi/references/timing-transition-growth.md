# 时机、转型与增长 playbook

## 覆盖路由

- `timing-action`：融合 `choose-wait-ride-or-face` 与 `timing-momentum-discipline`。
- `rooted-transition`：融合 `escalate-commitment-with-downside-gates` 与 `rooted-pilot-transition`。
- `success-risk`：承接 `success-risk-inversion`。

## 等待、借势或面对

1. **定义动作与期限**：明确要决定的动作、最晚日期、默认不行动及其后果。
2. **检查五个变量**：
   - 等待会增加什么信息？
   - 等待成本是否随时间上升？
   - 现在行动是否可逆？
   - 损失会不会因拖延扩大？
   - 需求、资源、协作者和反馈是否持续改善？
3. **识别主阻塞**：外部条件未熟、趋势正在形成，或内部恐惧性回避；只用可检验描述，不用“运没到”。
4. **选择分支**：
   - 等待：仅在能增加信息、降低风险或换来条件变化时使用，并设日期与指标。
   - 借势：至少三类持续信号成立且有反证检查；每次只提高一级投入。
   - 面对：拖延增损且主要障碍是回避时，做一个可撤回、有支持的小步。
   - 停止/退出：核心假设已失效、继续只增加不可恢复损失时采用。
5. **事后校准**：比较事前判断和结果，记录误差，不用成功/失败倒推命运。

## 保根基的转型与投入升级

1. **列保护线**：基本生活、健康、照护、现金储备、关键技能、客户、资质和回退路径。
2. **写可检验假设**：明确用户/结果、验证指标、期限和失败阈值。
3. **圈定最小试点**：限制客户、地点、时间、人员、权限和最大损失；失败不得击穿保护线。
4. **验证可重复性**：至少观察需求、交付、复购/持续反馈、单位经济或资源消耗与关键风险；一次顺利不算模式成立。
5. **合作五维核验**：共同目标与方案、能力互补、利益/控制权、履约证据、冲突/退出机制。
6. **选择投入等级**：维持、缩小、再试一轮、并行、分级扩大或退出；每次只升一级。
7. **写退出线与知情人**：说明何时停止、谁承担风险、谁依法或按职责必须知情。

命中以下任一项时不升级：宣称必成、拒绝账目/权限透明、试点无法验证、归零伤及生活根基、退出机制缺失、靠沉没成本或面子推动。

## 顺境反向风险扫描

1. **列放大信号**：增长、赞誉、资金、权力、订单或传播量发生了什么变化。
2. **查六类脆弱点**：单点依赖、激励变化、质量/安全、隐私/合规、现金流、被压住的反对意见。
3. **按影响、概率、可逆性排序**：选前三项有证据的风险，不制造无根据悲观。
4. **先降暴露再扩张**：设置容量、备份、限额、独立审查、质量闸门或暂停点，并指定责任人与复查日期。
5. **复查趋势承载**：用复购、质量、现金流、团队负荷和投诉判断继续、维持或降速。

## 输出重点

- 把“等”写成带日期和信息目标的动作，而非拖延。
- 把“冲”写成分段投入和停止条件，而非 all in。
- 把“辞职/创业”写成根基、试点、升级与退出四段。
- 成功后必须指出一个最可能被好消息遮住的风险。
